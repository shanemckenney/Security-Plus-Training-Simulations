Cloud Architecture Drag & Drop

Drag each cloud architecture component from the Legend into the appropriate drop zone in the network diagram. Each drop zone is marked with a “?”. Use the dropdown in the middle subnet to select its correct type (Public or Private). Place the components based on where they would logically reside in a typical secure cloud infrastructure. Once a component is placed it will be locked in and will not be able to be replaced! Click submit once ALL drop zones have been filled and the drop down has been selected.
