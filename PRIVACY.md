# Privacy Policy

## Overview

Security+ Training Simulations is a static, browser-based training project designed for cybersecurity education and certification readiness practice.

This project does not collect, store, transmit, process, or share personal information.

The simulations are designed to run locally in the user's browser without accounts, tracking, analytics, databases, or backend services.

---

## Information Collected

This project does not collect any personal information.

The project does not collect:

- Names
- Email addresses
- Student IDs
- Usernames
- Passwords
- Scores
- Completion records
- IP addresses
- Device identifiers
- Browser fingerprints
- Location data
- Analytics data
- Interaction logs

Any scoring, feedback, or answer checking occurs locally in the browser during the simulation session.

---

## Student Data

No student data is collected or stored by this project.

The simulations do not include login functionality, user profiles, form submissions, databases, or server-side processing.

If an instructor uses these simulations in a classroom setting and chooses to record student completion or performance separately, that recordkeeping occurs outside this project and is the responsibility of the instructor or institution.

---

## Local Browser Activity

Some simulations use JavaScript to provide interactive behavior such as:

- Checking selected answers
- Displaying feedback
- Resetting activities
- Supporting drag-and-drop interactions
- Simulating command-line activity

This behavior occurs locally in the browser.

No simulation activity is transmitted to the project owner, GitHub, or any third-party service by the application code.

---

## Cookies and Tracking

This project does not use:

- Cookies
- Tracking pixels
- Analytics scripts
- Advertising tools
- Third-party tracking
- Session monitoring
- Embedded external services

---

## Third-Party Services

This project is hosted using GitHub Pages.

GitHub may process standard web server logs or technical data as part of providing the GitHub Pages hosting service. That processing is governed by GitHub's own policies and is outside the control of this project.

The project itself does not intentionally collect, access, or process visitor data.

---

## External Links

This project may include links to repository documentation or related project files.

Users should review the privacy practices of any external websites they choose to visit.

---

## Children's Privacy

This project is intended for cybersecurity education and certification readiness.

It does not knowingly collect information from children, students, or any other users.

Because no personal data is collected, no student records are created by this project.
