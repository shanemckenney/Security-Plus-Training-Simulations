Site-to-Site VPN Configuration

Click each VPN concentrator to configure its Phase 1 and Phase 2 settings. Use the most secure algorithms available and configure peer IPs to point to the opposite site's concentrator.

You are responsible for setting up a site-to-site VPN to securely connect two remote networks. The configuration must use the most secure encryption algorithms available to ensure confidentiality and integrity. All traffic between the two sites should be fully encrypted over the VPN tunnel. Authentication between the VPN concentrators must use a shared secret password so that only trusted devices can form the connection.

Click VPN1 or VPN2 to open the configuration panel.

Instructor-created VPN configuration simulation using fictional network addresses for skills development; not representative of any certification exam content.
